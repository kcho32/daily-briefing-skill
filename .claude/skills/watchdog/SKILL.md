# Watchdog — 브리핑 실패 알림

브리핑 루틴은 실패해도 아무도 알려주지 않는다 (2026-10 실측: 날짜 착각으로 하루치 브리핑 누락, 서버 메모리 초과 다운, 커넥터 도구 꺼짐 — 모두 조용히 지나갔다). 이 스킬은 **결과물(대시보드)이 제때 나왔는지**만 확인하고, 문제가 있을 때만 알린다.

**하지 않는 것**: 시장 분석, 계좌 조회, 추천, 브리핑 대신 쓰기, 재실행. 문제를 *알리기만* 한다.

## 도구
- `notifier_mcp`: `list_recent_dashboards` (개인·공개 채널), `send_telegram_message` (개인 채널만)
- Bash `curl`: 서버 상태 확인

## 시각 기준
루틴 시계와 실행 안내는 UTC 다. **지금(KST) = 실행 시각(UTC) + 9시간.** 아래 "오늘"은 KST 날짜.

## 실행 절차

### 1. 어떤 회차인지 정한다
- KST 06:00~12:00 → **아침 회차**
- KST 18:00~24:00 → **저녁 회차**
- 그 외 → 아무것도 보내지 않고 종료 (예상 밖 실행)

### 2. 발행 확인

`notifier_mcp.list_recent_dashboards(limit=15)` (개인) 와 `list_recent_dashboards(limit=5, channel="public")` (공개) 를 받는다. 각 항목의 `created_at` 은 KST 시각이다.

**아침 회차** — 오늘(KST) 이 시각 범위에 있어야 할 것:

| 브리핑 | 찾는 방법 | 정상 |
|---|---|---|
| 공개 (market-radar) | 공개 목록 | 오늘 07:00 이후 1건 |
| 개인 (daily-briefing) | 개인 목록, 제목이 `포트폴리오 브리핑` 으로 시작 | 오늘 07:00 이후 1건 |
| 회고 (월요일만) | 개인 목록, 제목에 `회고` | 오늘 05:30 이후 1건 |

**저녁 회차**:

| 브리핑 | 찾는 방법 | 정상 |
|---|---|---|
| evening | 개인 목록, 제목이 `포트폴리오 evening update` 로 시작 | 오늘 21:30 이후 1건 |

- 0건 → **미발행**
- 2건 이상 → **중복 발행** (루틴이 여러 번 실행됨)
- 목록 조회 자체가 실패하면 → notifier 서버 문제로 본다 (아래 3 에서 확인)

### 3. 서버 상태

```
curl -s -m 60 -o /dev/null -w "%{http_code}" https://portfolio-mcp-jdao.onrender.com/health
curl -s -m 60 -o /dev/null -w "%{http_code}" https://notifier-mcp.onrender.com/health
```

무료 인스턴스는 잠들어 있다가 깨는 데 시간이 걸린다 — 200 이 아니면 30초 뒤 한 번 더. 그래도 200 이 아니면 **서버 응답 없음**.

### 4. 알림 (문제가 있을 때만)

문제가 하나라도 있으면 `notifier_mcp.send_telegram_message(text=...)` 를 **한 번** 보낸다 (`channel` 지정하지 않음 = 개인 방. 단톡방으로는 절대 보내지 않는다):

```
🚨 <b>[감시] MM-DD HH:MM</b>
• 개인 브리핑 미발행 (마지막: MM-DD HH:MM)
• 공개 브리핑 중복 발행 2건 (HH:MM, HH:MM)
• portfolio 서버 응답 없음 (HTTP 502)
→ 루틴 실행 기록 확인 필요
```

- 문제 항목만 쓴다. 원인을 추측해 적지 않는다 ("미발행"이지 "날짜 착각으로 미발행"이 아니다).
- notifier 서버가 죽어 텔레그램을 보낼 수 없으면 할 수 있는 게 없다 — 종료 메시지에 그 사실만 남긴다.

**문제가 없으면 아무것도 보내지 않는다.** 단 **월요일 아침 회차**에는 감시 자체가 살아 있다는 확인으로 한 줄을 보낸다:
`✅ [감시] 지난주 정상 작동 중 — 이상 있을 때만 알립니다`

## 하지 않는 것 (다시)
- 브리핑을 대신 만들거나 루틴을 다시 실행하지 않는다
- 계좌·시장 데이터를 조회하지 않는다 (portfolio 커넥터가 없어도 된다)
- 공개 채널로 보내지 않는다
