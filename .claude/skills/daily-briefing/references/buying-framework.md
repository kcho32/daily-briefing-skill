# 매수 의사결정 프레임워크

**언제 읽나**: 신규 매수 후보를 추천할 때, 또는 기존 보유 종목 추가 매수 검토 시.
**역할**: 수익률을 크게 갉아먹는 환율·세금·타이밍·상관관계·시나리오를 통일된 절차로 적용.

**전체 흐름**:
1. **게이트 1**: 후보를 100점 점수화 (정량 일관성)
2. **게이트 2**: 보류 룰 적용 — 미통과 시 추천 제외
3. **상세 평가**: 게이트 통과 후보에 §1~§7 적용 후 최종 추천

---

## 게이트 1: 후보 100점 점수화

매일 동일한 6축 기준으로 점수를 매겨 LLM 판단의 분산을 줄인다. 점수와 근거를 brief 본문에 명시.

| 축 | 만점 | 평가 기준 |
|---|------|---------|
| **밸류** | 20 | 선행 PER/PBR이 동종업계·역사적 평균 대비 매력 + **재평가 catalyst 여지** (단순 저평가 +10~15 / catalyst-driven 저평가 +18~20 / 동종 평균 +10 / 고평가 0). catalyst 예: 정책 변화·실적 모멘텀·구조조정·자사주 소각 발표 |
| **펀더** | 20 | 6개 sub-criteria 합산 (아래 표) — 회사 자체의 질 |
| **모멘텀** | 15 | 분석가 상향 + 차트(현재가 > ma50 > ma200) + 거래량 동반 (3개 충족 +15, 2개 +10) |
| **거시 정합** | 15 | 현 거시 환경(금리 사이클/달러/유가)에서 유리한 섹터인가 (정합 +15, 중립 +7, 역행 0) |
| **리스크** | 15 | hidden risk 심각도 — 낮을수록 가산 (없음 +15, 경미 +10, 진행 중 +5, 심각 0) |
| **포지션 핏** | 15 | 사용자 보유와의 시너지/중복 — 보완 +15, 부분 중복 +7, 완전 중복 0 |
| **합계** | **100** | |

### 펀더 축 sub-criteria (20점)

단순히 "ROE 좋음" 으로 묶지 말고 6개 축으로 분해 — **대장주 프리미엄과 주주환원 적극성도 점수에 반영**.

| 항목 | 만점 | 평가 기준 |
|------|------|---------|
| 매출/EPS 성장률 | 0~4 | 3년 CAGR 또는 최근 분기 yoy — 두 자릿수 +4 / 한 자릿수 +2 / 역성장 0 |
| 영업이익률 (마진) | 0~3 | 동종업계 상위 +3 / 평균 +1 / 하위 0 |
| **ROE 지속성** | 0~4 | 3년 평균 ROE + 추세 — 10%+ 지속 +4 / 일시적 10% +2 / 한 자릿수 0 |
| 부채비율 | 0~3 | 동종업계 평균 대비 양호 +3 / 평균 +1 / 과다 0 |
| **섹터 내 지위** ⭐ | 0~3 | 1위 대장주 +3 / 2~3위 +1 / 후순위 0 (시장 점유율·브랜드 프리미엄) |
| **주주환원 정책** ⭐ | 0~3 | 적극적(자사주 소각 + 배당 정책 명시) +3 / 보통(정기 배당만) +1 / 미흡 0 |

⭐ 표시는 단순 ROE·마진 비교로는 안 잡히는 두 가지 프리미엄 — 섹터 지위와 주주환원 적극성. 같은 ROE 라도 섹터 1위 종목이 후순위보다, 자사주 소각하는 회사가 단순 배당만 하는 회사보다 펀더 점수에서 앞선다.

**판정 기준:**
- **80점+**: 매우 매력적 → Top 1~3 후보로 명시 추천
- **65~79점**: 매력적 → 후보 풀에 포함, 분할 비중
- **50~64점**: 한계 → 게이트 2 적용 (대부분 보류)
- **< 50점**: 제외 — brief 에 등장 X

**점수 출력 형식 (각 후보별):**

```
[종목] [합산]/100
└ 밸류 [N] / 펀더 [N] (성장 [N]·마진 [N]·ROE [N]·부채 [N]·대장주 [N]·환원 [N]) / 모멘텀 [N] / 거시 [N] / 리스크 [N] / 포지션핏 [N]
└ 강점: [상위 축 1~2개]
└ 약점: [하위 축 1~2개]
```

펀더의 sub-breakdown 은 **항상** 노출 — 대장주·환원 점수가 어떻게 들어갔는지 사용자가 검증 가능해야 함.

## 게이트 1.5: Top 후보 3-Lens 비교 (점수 박빙 시)

**트리거**: 게이트 1 통과 후보 중 합산 점수가 **±5점 이내** 인 후보가 2개 이상일 때.
**역할**: 단일 합산 점수로는 안 보이는 차이를 3개 렌즈로 재정리. 사용자가 어느 강점을 우선할지 직접 판단 가능하게.

| 렌즈 | 정의 | 주로 어느 점수 축에서 가져오나 |
|------|-----|------------------------|
| **절대 퀄리티** | 회사 자체의 질 — 영구/장기 보유 가치 | 펀더(특히 섹터 지위·주주환원·ROE 지속성) + 리스크 |
| **현재 가격 매력** | 지금 사면 얼마나 싼가, 재평가 여지 | 밸류 + 모멘텀 |
| **포지션 핏** | 사용자 포트폴리오 시너지·다각화 | 포지션 핏 + 거시 정합 |

각 렌즈를 0~100 으로 재환산 (LLM 정성 평가 — 엄격한 수식이 아니라 비교 가능한 점수). 합산 점수와 별개.

**출력 형식 (Top 후보 2~3개):**

```
🔍 Top 후보 비교 (점수 박빙)

[종목 A] 합산 [N]
└ 절대 퀄리티 [N] / 가격 매력 [N] / 포지션 핏 [N]

[종목 B] 합산 [N]
└ 절대 퀄리티 [N] / 가격 매력 [N] / 포지션 핏 [N]

→ [A]: [한 줄 캐릭터 — 예: "더 좋은 회사, 안정성"]
→ [B]: [한 줄 캐릭터 — 예: "더 싸고 재평가 여지 큼"]

💡 매수 방식 옵션:
  • 밸런스: A [%] + B [%]
  • 퀄리티 우선: A 단독
  • 저평가 베팅: B 단독
```

**판단 가이드 (어느 옵션 추천?):**
- 사용자 포트폴리오가 이미 성장주 위주 → 퀄리티 우선 (안정 보완)
- 적립식 + 분할 매수 가능 → 밸런스
- 위기 모드 / 보수적 모드 → 퀄리티 우선
- 거시 환경이 재평가 catalyst 있음 (예: 금리 인하 사이클 진입) → 저평가 베팅

## 게이트 2: 매수 보류 룰

점수가 충분해도 다음 조건 중 **하나라도** 해당하면 추천 보류. brief 에 "보류 사유" 명시.

| 보류 조건 | 임계값 | 출력 예시 |
|---------|------|---------|
| 점수 미달 | < 50 | `보류 — 점수 47/100, 기준 미달` |
| 환율 부담 (해외 종목) | USD/KRW > 1,400 | `보류 — 환율 1,415원, 다음 분할 환전까지 대기` |
| 이벤트 직전 | FOMC/CPI/NFP/한은 금통위/어닝 D-2 이내 | `보류 — FOMC D-1, 발표 후 재평가` |
| 당일 급변 | 후보 종목 당일 ±5% 이상 | `보류 — 당일 +6.8% 급등, 추격 매수 위험` |
| 현금 부족 | 매수가능 현금 < 다음 입금분의 30% | `보류 — 현금 28만원 < 다음 입금 30% (45만원)` |
| 위기 모드 + 신규 매수 | 위기 트리거 발동 시 신규 후보 추가 | `보류 — 위기 모드, 신규 매수 일시 중단` (단 안전자산은 예외) |
| 가드레일 위반 카테고리 | 후보가 한도 초과 섹터/테마 소속 (SKILL.md 가드레일 참조) | `보류 — AI 테마 한도 초과 (현재 71%)` |

**예외 (보류 룰 무효화):**
- 위기 모드의 안전자산(KRX 금현물, TLT 등): 환율·이벤트 룰 무시
- 사용자가 명시적으로 "지금 사도 되나" 질문 시: 보류 사유 알리되 사용자 판단에 맡김

## 1. 환율 고려 (수익률 직격)

미국 주식 / GLD 등 달러 표시 자산. 원화 강세 전환 시 종목이 올라도 환차손 가능.

**brief 매일 표기:**
- 현재 USD/KRW (`get_portfolio_data` 의 `currency_breakdown.fx_rate` 사용)
- 1,400원대 매수 시: `⚠️ 환율 부담 — 분할 환전 권장 (3~4회 분할)`
- 1,350원 이하 시: `🟢 환율 부담 적음`
- 환율 추세 한 줄 (강달러/약달러)

추가로 currency_breakdown 에 `fx_rate_change_pct` 가 있으면 "전일 대비 +/-X%" 도 한 줄.

## 2. 세금 최적화 (사용자 공제 0원 가정)

**세금 영향 우선순위:**

| 자산 유형 | 양도세 | 배당세 |
|----------|--------|--------|
| 미국 개별주 | 22% (250만 공제, **이미 소진**) | 미국 원천 15% + 한국 종합과세 |
| 미국 ETF | 22% (위와 동일) | 좌동 |
| **한국 개별주 (소액주주)** | **비과세** ⭐ | 한국 14% (분리과세 가능) |
| **KRX 금현물 ETF** (KODEX 골드 132030, ACE 금선물 등) | **비과세** ⭐ | 없음 |
| ISA / 연금계좌 | 비과세 / 과세이연 | 좌동 |

**적용 룰:**
- GLD 추천 시 → **KRX 금현물 ETF 대안 비교 필수**: KODEX 골드(132030), ACE 골드(411060) 등 → 세금 측면 한국이 훨씬 유리
- 미국 ETF 보수 비교: GLD 0.40% vs IAU 0.25% vs GLDM 0.10% → 같은 자산이면 더 저렴한 쪽 추천
- 한국 우량주와 미국 동급 비교 시 **세금 후 수익률**로 평가

**배당 종합과세 주의:**
- 한국 금융소득 연 2,000만원 초과 시 누진세
- 다배당주(배당률 ≥2%)는 누적 계산 필요 — 후보별 배당률은 매일 데이터로 확인

## 3. 분할 매수 원칙 (타이밍 리스크 완화)

**위험자산 (단일 종목 / GLD 등) 매수 시:**
- 3~4회 분할 (매주 1/3, 또는 매월 1/3씩)
- 사용자 적립식 입금 1회분의 전부를 한 종목에 넣지 말 것

**매수 회피 시점 (brief에서 자동 감지):**
- 당일 ±5% 이상 급등/급락 종목 (모멘텀 추격 위험)
- CPI / FOMC / NFP / 한은 금통위 발표 직전 24~48시간
- 보유 종목 어닝 발표 직전 (D-2 이내)
- 지정학 이벤트 진행 중 (호르무즈, 미중 등)

**현금 유보 권장: 신규 자금의 10~20%**
- 이벤트 후 추가 매수용
- 단기 급락 시 매수 기회

## 4. 종목 간 상관관계 / 중복 노출 체크

신규 후보 추천 시 다음을 명시:

| 체크 | 무엇을 검증하나 |
|------|------|
| 같은 섹터 중복 | 후보 + 기존 보유에서 같은 섹터 합산 비중 — 한도(30%) 근접/초과 시 한쪽 줄이거나 한쪽만 추천 |
| 동일 거시 노출 | 같은 거시 변수(금리·달러·유가)에 동일 방향 노출이면 분산 효과 제한 |
| 같은 트렌드/테마 | 같은 테마(예: AI 반도체, EV, 금) 합산 비중이 한도(40%) 근접 시 자제 |
| 같은 거시 방어 카테고리 | 침체 방어(헬스케어/유틸)·인플레 방어(금/원자재) 등 같은 방어 역할 중복 |

**원칙**: 비슷한 노출 종목은 **하나만** 추천. 진짜 다른 노출(예: 금/장기채 같은 헷지)은 별도.
각 종목이 어느 섹터/테마/거시에 속하는지는 매일 데이터·뉴스 기반으로 판단 (고정 분류 표를 외워서 쓰지 말 것).

## 5. Hidden Risk 식별 (추천 전 의무)

**모든 매수 추천에는 종목별 hidden risk 1개를 명시한다.** 미리 정의된 표를 인용하지 말고, 직접 조사해서 *현재* 상태 기준으로 서술한다.

**카테고리 (체크할 영역):**

| 카테고리 | 무엇을 확인하나 | 검색 키워드 예시 |
|---------|-------------|--------------|
| 소송 | 진행 중 집단소송, 합의 변동성 | `{종목} lawsuit settlement 2026` |
| 규제 | 정부 정책 / 반독점 / 상장 규제 | `{종목} regulation 2026`, 한국 종목은 정책 관련 한국어 검색 |
| 회계 | SEC/금감원 조사, 감사 의견 | `{종목} SEC investigation`, `{종목} audit` |
| 정치 | CEO 정치 리스크, 정부와의 관계 | `{종목 또는 CEO} political risk` |
| 의존도 | 단일 고객 / 단일 시장 / 단일 제품 의존 | `{종목} customer concentration` |
| 밸류에이션 | 선행 PER 극단치, 성장 둔화 | `{종목} forward PE`, `{종목} valuation` |
| 경쟁 | 점유율 하락, 신규 경쟁자 진입 | `{종목} market share 2026` |

**판단 룰:**
- 검색 결과로 *현재* 진행형 리스크 1개 추출 — 과거 사건이 해소됐으면 언급하지 않는다.
- 리스크가 매력보다 크다고 판단되면 추천에서 제외한다.
- ETF 추천 시에는 동일 자산군의 보수 더 낮은 / 세금 더 유리한 대안 비교가 hidden risk 보다 우선한다 (예: GLD → KRX 금현물 비과세).

**출력 형식:**
- 일반: `🔻 리스크: [현재 상태 1줄]`
- 제한적: `⚠️ 주의: [현황]`
- 추천 제외 사유: 본문에 별도 한 줄로 명시

## 6. 출구 전략 / 리밸런싱 룰 (매수 시점에 반드시 정의)

**매수 추천 시 다음 3가지 동시 명시 (없으면 추천 불완전):**

1. **손절 라인** (Stop Loss)
   - 종목별 -15% (보수) 또는 -20% (공격)
   - **또는 매수 근거 훼손 시**: "추천 시 핵심 catalyst(컨센서스/타겟/펀더)가 깨지면 손절" — 각 종목별 catalyst 를 매수 시점에 명시
   - 가능하면 `ma200 - 2*atr20` 동적 라인 병기 (시세 앵커 활용 — SKILL.md 본문 참조)

2. **익절 기준** (Take Profit)
   - 분석가 평균 목표가 도달 시 30~50% 차익실현
   - 또는 기술적 트리거: `week52_high * 0.97` 근접 시 단계 익절 검토
   - 출력 형식: "[종목] $[목표가] 도달 시 [%] 익절" — 가격은 데이터에서 직접 산출

3. **리밸런싱 트리거**
   - 분기별 (3/6/9/12월 1주차) 비중 점검
   - 비중이 목표 대비 **±5%p 이탈** 시 즉시 조정
   - 한 종목이 15% 초과 시 자동 조정 (집중 위험 룰은 SKILL.md 본문 참조)

## 7. 시나리오 스트레스 테스트

추천 결정 전 4가지 시나리오로 영향 평가:

**4가지 거시 시나리오:**
- 금리 인하 가속
- 인플레 재발
- 침체 진입
- 지정학 완화 / 긴장 고조

**각 시나리오 × 후보별로 영향(+/−/0)을 직접 평가**한다. 일반 가이드라인 참고용:

| 카테고리 | 침체 방어 | 인플레 방어 | 금리 인하 수혜 |
|---------|---------|----------|------------|
| 금/원자재 | + | ++ | + |
| 장기채 | + | − | ++ |
| 금융 (전통은행) | −− | + | − (NIM↓) |
| 헬스케어/필수소비재 | + | 중립 | + |
| 빅테크/성장주 | − | − | ++ |
| 자동차/내구재 | −− | − | + |

위 표는 일반 패턴일 뿐 — 개별 후보 사업 모델·매출 구성에 따라 다를 수 있으므로 매일 후보별로 직접 판단.

**판단 기준:**
- 추천 포트폴리오가 한 시나리오에서 -30%+ 손실 → **재구성**
- 4가지 시나리오 중 2개 이상에서 견고 → 통과
- 헬스케어/금 = 침체 방어, 금융 = 인플레 방어 → 균형 중요
