# 위기 모드 플레이북

**언제 읽나**: AI 가 거시 환경·포트폴리오 변동·신용 스프레드 등을 종합 판단해서 **위기 신호 강함** 으로 결론낸 경우 (SKILL.md Step 3 참조).
**역할**: 위기 시 일관된 톤·접근을 유지하기 위한 가이드. 구체적 처방 없음 — AI 가 상황 보고 자율 판단.

---

## 위기 모드 톤 가이드

위기 신호 판단 시 메시지 톤에 다음 원칙을 유지:

- **"지금 당장 ~~ 해라" ❌ → "현 상황에서 ~~ 고려" ⭕**
- 단정·공포 톤 회피. 사용자가 흔들리지 않게 사실 + 옵션 제시.
- 디리스크 제안은 구체적으로 — 어느 종목·얼마·시세 앵커 기반 트리거 가격까지 명시.

**판단 근거 설명 방식 — cluster 기반:**

위기 판단 narrative 작성 시 *단일 지표만 가지고 공포 조장하지 말 것*. SKILL.md Step 3 의 cluster 원칙과 일관되게:
- ❌ "VIX 가 32 다. 위기다." (단일 지표 단정)
- ⭕ "VIX 32 + HY 스프레드 8.5% 동반 확대 + 주요 지수 -3% 동반 하락 + 포트폴리오 고베타 종목 평균 -5% — 시그널 cluster 가 위기 신호" (cluster 기반)

사용자가 *어떤 시그널 묶음* 으로 판단했는지 검증 가능하게.

## 위기 모드 출력 형식

```
🚨 [날짜] ([요일]) — 위기 신호

⚠️ AI 판단 근거 (어느 지표가 위기 신호로 판단됐는지)
[지표 + 값 + narrative — 왜 위기 신호로 판단했는지]

🎯 권장 조치 (디리스크 + 적립식 강점 활용)
[AI 가 종합 판단해서 구체적 조치 제시 — 디리스크할 종목·비중, 안전자산 후보, 추가 매수 보류 또는 활용 등]
[적립식 강점도 함께 — 위기는 평단 낮춤 기회이기도 함]
```

## 적립식 투자자의 위기 시 관점

시장 폭락은 적립식 투자자에게 일반 투자자와 다른 의미를 가짐:

- 신규 자금이 매월 들어오기 때문에 *폭락은 매수 기회* 가 될 수 있음 — 평균 매수가 큰 폭으로 낮춤
- 단, 펀더 훼손이 명백한 종목은 그래도 디리스크 우선
- 폭락 초기엔 신중하게 (더 내릴 수 있음), 어느 정도 안정된 뒤 적극 매수가 역사적으로 회복기 직전 패턴

위 관점을 AI 가 시장 상황(폭락 단계·VIX 추세·신용 스프레드 흐름) 보고 균형 잡힌 narrative 로 전달.

**디리스크 vs 추가 매수의 충돌:**
- 펀더 훼손·집중 위험 종목 → 디리스크 우선 판단 가능
- 펀더 견고·시장 패닉만으로 하락 → 추가 매수 후보로 판단 가능
- AI 가 종목별로 판단해서 사용자에게 옵션 제시

## 위기 시 안전자산 참고

위기 시 자주 검토되는 자산군 (AI 가 상황에 맞게 선택·우선순위 결정):

- **KRX 금현물 ETF** (KODEX 골드 132030, ACE 골드 411060) — 한국 비과세 ⭐
- **현금 (KRW)** — 즉시 활용, 환전 비용 없음
- **미국 금 ETF** — GLD (0.40%), IAU (0.25%), GLDM (0.10%) — 22% 양도세
- **미국 장기채** — TLT 등, 금리 인하 수혜 — 22% 양도세
- **한국 단기채 ETF** — KRW 표시, 금리 노출 적음, 비과세

세금 후 수익률·보수·노출 성격을 비교해서 AI 가 사용자 상황에 가장 적합한 것 추천. 정해진 우선순위 표 없음.

## 위기 모드 종료 판단

AI 가 거시 환경·포트폴리오 변동·시장 분위기를 종합 판단해서 위기 신호가 *명확히 해소* 됐다고 결론날 때 일반 모드로 복귀.

**참고할 회복 신호 (정황 판단):**
- VIX 가 평소 수준으로 회귀하고 며칠 안정
- HY 신용 스프레드 정상화
- 장단기 금리 역전이 의미 있게 완화
- 포트폴리오 일일 변동이 평상 수준으로 회복

종료 후 첫 brief 에 "위기 모드 종료, 회복기 진입" 한 줄 + 폭락 기간 평균 매수가 효과 회고.
