# 추천 성과 회고

**언제 읽나**: 매주 월요일 brief(7일 회고) / 매월 1일 brief(30일 회고) / 사용자 "회고" 요청 시.
**역할**: 과거 추천이 실제로 어떻게 됐는지 측정해서 "좋은 분석" → "**같은 기준으로 매일 판단**" 으로 끌어올린다.
정성 회고가 아니라 정량 + 실패 카테고리화.

---

## 데이터 수집 절차

### 1. 과거 추천 추출

```
notifier_mcp.list_recent_dashboards(limit=30)
```

각 대시보드에서 다음을 파싱:
- 추천 종목 (매수/매도)
- 추천 날짜
- 추천 시 점수 (game 1 결과, 있으면)
- 추천 시 가격 (시세 앵커 기록값)

### 2. 현재가 + 변동률 계산

```
portfolio_mcp.get_portfolio_data()
```

- 보유 종목 → 응답의 `current_price` 사용
- 보유하지 않는 후보 종목 → 웹 검색으로 현재가 확인 (`"{종목} stock price"`)

각 추천 종목에 대해:
- **수익률** = (현재가 − 추천 시 가격) / 추천 시 가격 × 100
- **벤치마크 대비** = 수익률 − 같은 기간 S&P500(미국) 또는 KOSPI(한국) 변동률

### 3. 실현 손익 (실제 매매한 경우)

```
portfolio_mcp.get_realized_pnl()
portfolio_mcp.get_trading_history(period_days=30)
```

추천대로 매매했는지 + 결과 손익 확인.

## 7일 회고 (매주 월요일)

지난 7거래일 동안의 추천을 평가.

### 출력 형식

```
📊 주간 추천 회고 (2026-05-04 ~ 2026-05-10)

추천 건수: 매수 X / 매도 Y / 보류 Z
적중률: A/B (양의 수익률 비율)
평균 수익률: +/-x.x% (벤치마크 대비 +/-x.x%p)

🟢 잘 된 추천 (Top 3):
1. [종목] 추천일 → 현재 +x.x% (벤치마크 +y.y%, 초과 +z.z%p)
   └ 점수 81 — 펀더·모멘텀 적중
2. ...

🔴 실패한 추천 (≤ -5% 또는 벤치마크 대비 -3%p 이하):
1. [종목] 추천일 → 현재 -x.x% (벤치마크 -y.y%, 초과 -z.z%p)
   └ 실패 카테고리: [거시 오판 / 리스크 누락 / 이벤트 직전 / 타이밍]
   └ 교훈 한 줄

📌 이번 주 학습:
- [패턴 1줄: 예 "모멘텀 점수 낮은 종목 추천 회피 효과 확인"]
```

## 30일 회고 (매월 1일)

7일 회고와 동일 구조 + 카테고리별 통계:

```
📊 월간 추천 회고 (2026-04-01 ~ 2026-04-30)

[7일 회고 형식과 동일]

📈 점수대별 적중률:
- 80+: A/B (xx%)
- 65~79: A/B (xx%)
- 50~64: A/B (xx%)

🎯 실패 카테고리 분포 (실패 N건 중):
- 거시 오판: x건 — [구체적 원인 한 줄, 실제 회고에서 도출]
- 리스크 누락: x건 — [구체적 원인]
- 이벤트 직전: x건 — [어느 이벤트가 보류 룰 미적용]
- 타이밍: x건 — [어떤 룰을 어겼는지]

💡 다음 달 개선:
- [카테고리별 1줄씩]
```

## 실패 카테고리 정의

추천이 -5% 이상 손실이거나 벤치마크 대비 -3%p 이하면 실패로 분류. 원인을 다음 4가지 중 하나에 매핑.

| 카테고리 | 정의 | 예시 |
|---------|------|------|
| **거시 오판** | 추천 시 거시 가정(금리·달러·유가)이 실제와 어긋남 | "금리 인하 사이클 가정 → Fed 매파 전환으로 빅테크 -10%" |
| **리스크 누락** | hidden risk 식별 단계에서 놓친 이슈가 현실화 | "후보 추천 시 특정 리스크 카테고리 과소평가" |
| **이벤트 직전** | 게이트 2의 D-2 룰 위반 또는 발견 못한 이벤트 | "추천 다음날 어닝 미스, 사전 어닝 일정 누락" |
| **타이밍** | 분할 매수·환율·점수 룰을 무시한 추천 | "환율 1,420원에 단일 매수 추천 → 환차손 -3%" |

## 회고 후 SKILL.md 반영

회고에서 **반복되는 실패 카테고리**가 나오면 다음 brief 부터 해당 영역 강화:

- **거시 오판 반복** → Step 2(거시 환경) 에 해당 거시 변수 추적 강화
- **리스크 누락 반복** → §5 hidden risk 식별 시 검색 키워드 추가
- **이벤트 직전 반복** → 게이트 2의 D-2 룰을 D-3 로 확장
- **타이밍 반복** → 분할 매수 횟수 늘림 (3회 → 4회)

회고 결과는 회고 섹션에만 표시하고 SKILL.md 본문 수정은 사용자 동의를 받은 뒤 진행.
