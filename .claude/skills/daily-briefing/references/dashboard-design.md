# HTML 대시보드 디자인 가이드 (semantic 중심)

**언제 읽나**: Step 9 (HTML 대시보드 작성) 진입 시. 매일 발행이므로 사실상 매일 1회.
**역할**: *구조와 의미* 를 강제하고 *시각 톤은 AI 자율*. 매일 시각이 약간 달라져도 사용자가 *항상 같은 정보를 같은 위치에서* 찾을 수 있게.

> **대시보드 = 진짜 풀 콘텐츠.** 텔레그램은 요약/trigger 일 뿐 — 사용자가 button 누르면 *여기서* 모든 디테일을 본다. 신규 후보 narrative, 사이즈 근거, 진입/손절/익절 가격, hidden risk, 매수 전 확인사항, 종목별 시세 분석 등 *모든 detail 은 대시보드에*.

---

## 디자인 원칙

- **모바일 우선** — 좁은 화면 (320~480px) 에서 잘 보이도록 표/카드 위주
- **정보 밀도** — 한 화면에 핵심 7~10개 정도 노출, 불필요 장식 최소화
- **시각 톤 (다크/라이트, 색상 팔레트, 폰트, max-width) 은 AI 자율** — spec 은 *구조와 의미* 만 강제. 매일 약간 달라도 OK
- **한 brief 내 시각 일관성 유지** — 같은 종류 카드는 같은 스타일, 같은 색은 같은 의미. 카드별 width·padding 균등
- **차트는 단순 SVG 또는 생략** — 외부 라이브러리 의존 X

## 표준 섹션 (순서 고정 — semantic 요구사항)

대시보드는 다음 순서로 12개 섹션 (조건부 sub-card 포함). 각 섹션은 *매일 풀* 또는 *조건부 압축* 모드로 라벨링 — **조건부 섹션도 카드 자체는 항상 표시** (한 줄 압축 가능, 완전 생략 X). 사용자가 *섹션 누락인지 정상 압축인지* 헷갈리지 않게.

| # | 섹션 | 모드 |
|---|---|---|
| 1 | 모드 배너 | 매일 풀 |
| 2 | 🎯 오늘 결론 (3줄 mini) | 매일 풀 |
| 3 | 거시 환경 | 매일 풀 |
| 4 | 포트폴리오 현황 (4a/4b/4c sub) | 매일 풀 |
| 5 | 추천 추적 | 매일 풀 |
| 6 | 보유 종목 분석 | **조건부 압축** |
| 7 | 🎯 오늘의 액션 (모드별) | 매일 풀 |
| 8 | 🎯 추천 매수 list / 0개 카드 (+ 8b/8c sub) | 매일 풀 |
| 9 | 📋 매수 전 확인사항 | 매일 풀 |
| 10 | 세금 시뮬레이션 | **조건부 압축** |
| 11 | 현금/입금 가이드 | **조건부 압축** |
| 12 | 이번 주 일정 | **조건부 압축** |

**섹션 상세:**

1. **모드 배너** (헤더) — 날짜 + 모드 + 위기 시 핵심 trigger 한 줄
2. **🎯 오늘 결론** (모바일 첫 화면 핵심) — 3줄 mini 카드. 사용자가 *스크롤 전에* 결론 파악
3. **거시 환경** — baseline 8 + AI 자율 추가 지표 + 위기·기회 cluster 평가 narrative
4. **포트폴리오 현황** (3 sub-cards):
   - 4a. 미국 + 한국 분리 (종목별 평가손익·비중)
   - 4b. **상대성과 카드** — 포트폴리오 vs S&P500/NDX/SOXX/KOSPI 일변동 + 핵심 벤치마크 ±%p
   - 4c. **비중 카드** — 단일 종목 고유위험 정보 한 줄(`ℹ️`, 매도 신호 아님)만, 없으면 ✅ 한 줄. 단계 사다리·국가비중 표시 X
5. **추천 추적** — ✅ 실행됨 (직전 brief 이후) + ⚠️ 미체결 유효 (carry-over 는 섹션 8 에 통합)
6. **보유 종목 분석** *(조건부 압축)* — 신호 발견 종목만 풀 narrative 카드. 신호 없으면 "특이사항 없음 — 점검: [종목 list]" 한 줄. 자세한 선정·압축 룰은 daily SKILL.md § Step 4 "보유 종목 경량화 원칙"
7. **🎯 오늘의 액션** — 모드별 (위기/액션/기회 등). 보유 종목 매도/매수, 시세 앵커 기반 가격
8. **🎯 추천 매수 list** (최대 5, 추천 강도 순) — 각 후보 풀 narrative 카드. fresh + carry-over 통합
   - 8b. **🔍 AI 가 보류 권고한 후보** (조건부) — 있을 때만
   - 8c. **🛡️ 헤지 제안** (조건부, 위기/이벤트 모드 한정) — 일반 후보와 시각 명확 분리
9. **📋 매수 전 확인사항** — 환율·세금·이벤트·앵커·집중도 narrative
10. **세금 시뮬레이션** *(조건부 압축)* — 매도/교체매매/실현손익 *변화* 있는 날 풀 카드 (KIS + Kiwoom 합산, 공제 잔여, 예상 세금). 변화 없으면 "공제 잔여 [값] / 변화 없음" 한 줄
11. **현금/입금 가이드** *(조건부 압축)* — 신규 입금 감지 또는 매수 추천 있는 날 분배 추천 풀 카드. 그 외엔 "매수가능 현금 [값]" 한 줄. *현금 한 줄은 매일 노출* (매수 결정에 매일 영향)
12. **이번 주 일정** *(조건부 압축)* — 오늘/내일 영향 큰 이벤트 (FOMC·CPI·핵심 어닝 등) 있는 날 풀 카드. 없으면 "이번 주 핵심 일정 없음" 한 줄

## 모드 배너 (시각 강도 요구사항)

대시보드 최상단에 배너 — *모드 강도* 와 *시각 강도* 가 매칭되어야 함:

| 모드 | 시각 강도 | 색상 방향 (AI 자율 hex) |
|---|---|---|
| 🚨 위기 | 강한 경고, 즉시 인식 | 빨간 계열 + 핵심 trigger 한 줄 명시 |
| 🟢 기회 | 명확한 강조 (긍정) | 녹색 계열 |
| 🎯 액션 | 중간 강조 | 파란 계열 |
| ⚠️ 리마인드 | 약한 강조 | 노란 계열 |
| ✅ 안정 | 차분, 부담 없음 | 녹색 차분 또는 회색 |

구체 hex 코드는 AI 자율 — 다만 *사용자가 한눈에 모드 구분 가능* 해야 함.

## 오늘 결론 카드 (섹션 2, 필수)

대시보드 첫 화면 UX 의 핵심. 사용자가 모바일에서 *스크롤 전에* 오늘의 결론을 먼저 본다. 텔레그램 한 줄 요약과 *같은 메시지* 가 대시보드 상단에도 노출되어 텔레그램 → 버튼 → 대시보드 일관성 강화.

**필수 요소 (3줄 narrative, 카드 안에 짧게):**

1. **오늘 새 액션 yes/no** — `🎯 새 액션 있음` 또는 `✅ 새 액션 없음` 한 줄
2. **있으면 *무엇·얼마나*** (요약) — 예: "🆕 추천 [N]종목 / 보유 [종목] 추가 매수 / 헤지 [수단]" — *종목명 + 액션 종류* 만, detail 은 아래 섹션
3. **없으면 *왜 현금/보유가 최선*** — 한 줄 사유 (예: "오늘 발굴 매력 약함 + 위기/기회 시그널 없음 — 현금 유지")

**시각 요구사항:**
- 모드 배너 *바로 아래* — 두 카드를 시각적으로 *연속 그룹* 으로 묶음 (배너 + 결론 = 헤더 zone)
- **다른 카드보다 약간 강조** (border 강조 / 살짝 큰 폰트 / 배경 톤 차별 등 — 방식 AI 자율)
- 3줄 짧게 유지 — 길어지면 첫 화면 UX 가치 사라짐
- 위기 모드면 사유 줄에 *trigger 한 줄* 명시

**왜 필요한가**: 11개 섹션이 풍부해도 사용자가 결론까지 도달하려면 스크롤. 이 카드가 *결정 흐름의 entrypoint* — 자세히 보고 싶으면 아래로, 결론만 보면 여기서 끝.

## 초보자 친화 — 지표/앵커 정의 노출 (공통 원칙)

대시보드에 등장하는 모든 *거시 지표* 와 *시세 앵커* 옆에는 **본질 정의 한 줄** 을 *괄호 또는 작은 글씨* 로 노출. 사용자가 매일 자연스럽게 학습 가능하게.

**spec 에 박힌 정의 (변하지 않는 사실) 와 LLM 자율 해석 (오늘 값 의미) 의 구분:**

| 영역 | 출처 |
|---|---|
| 지표 본질 정의 (예: "VIX = 시장 변동성 지수") | `daily SKILL.md § Step 2 baseline 표` 와 `§ 시세 앵커 활용 § 앵커 필드 표` 에 박힌 spec 그대로 사용 |
| 오늘 값 해석 (예: "평온권" / "위기 신호 약함") | LLM 자율 — narrative 안에서 cluster·종목 컨텍스트와 함께 |

**표시 형태 예시 (지표 정의는 spec 인용, 해석은 LLM 자율):**
```
VIX [값] (시장 변동성 지수, 높을수록 공포 ↑) — [오늘 해석 한 줄]
미국 10년물 [값]% (장기 금리, 성장주 밸류에 영향) — [오늘 해석 한 줄]
```

진입가 narrative 도 마찬가지:
```
진입가 $[값] (근거: ma200 [장기 추세선] 근처 + 52w 저점 +[X]% 위)
```

**적용 카드:**
- 거시 환경 카드 (섹션 3) — baseline 8개 + AI 자율 추가 지표
- 신규 후보 카드 (섹션 8) — 진입가/손절/익절 근거 narrative 안
- 보유 종목 분석 카드 (섹션 6) — 시세 앵커 인용 시
- 비중 카드 (섹션 4c) — 단일 종목 고유위험 `ℹ️` 한 줄 (있을 때만)

**원칙:**
- *변하지 않는 정의* 만 spec 박힌 텍스트 그대로 사용 (LLM anchoring 방지)
- *오늘 값 해석* 은 LLM 자율 — boilerplate template 금지 ("평온권" / "주의권" 같은 같은 표현 반복 X — 그날 컨텍스트에 맞는 narrative)
- 정의 노출이 *visual 부담* 되면 작은 글씨 / 괄호 / hover tooltip — 시각 weight 본문보다 낮춤

## 카드 구성 (공통 요구사항)

- 각 섹션 = 카드 (또는 카드 그룹)
- 명확한 title + body 구조
- **카드 간 시각 weight 균등** — 같은 width, 비슷한 padding
- **내용이 짧은 카드도 동등한 시각 weight** — 작아 보이거나 비어 보이지 X
- *같은 종류 카드는 같은 스타일* (예: 모든 신규 후보 카드는 같은 layout)

---

## 신규 후보 카드 (필수 요소)

각 후보 카드 (1~5위, 추천 강도 순) 가 반드시 포함:

- **종목명 + 순위 + 라벨** — `(NEW)` 또는 `(carry-over · Day N: 처음 추천 [날짜])`
- **추천 사유** 한 줄 요약
- **강점 narrative** — 펀더·밸류·모멘텀·catalyst 중 결정적인 것
- **약점 narrative** — cherry-pick 금지
- **Hidden risk** 한 줄 — 의무 표기
- **시세 앵커 가격** — 진입가·손절·익절 (값 + AI 가 사용한 앵커 조합 근거)
- **권고 사이즈** + 근거 (모드·컨빅션·변동성·세금·노출 narrative)

**시각 차별 요구사항:**
- 일반 카드와 *구분 가능한 요소* (좌측 border 강조 / 배경 차이 / 아이콘 등 — *방식은 AI 자율, 단 한 brief 내에서는 일관* )
- 점수표·매력 N/M 배지 금지 — narrative 로만 매력도 표현

**carry-over 인 경우 추가:**
- 처음 추천일 + 그동안 미체결 + 오늘도 유효한 이유 한 줄

**판단 메타 (retro 분석용, HTML comment — 사용자 UX 영향 X)**:

각 신규 후보 카드 *끝* 에 HTML comment 한 줄로 retro 가 parse 할 메타 박기:

```html
<!-- meta: anchor=[ma200+52w 저점 등 진입가 산출에 쓴 앵커 조합], ts=[YYYY-MM-DDTHH:MM KST 분석 시점], src=[yfinance|yfinance:stale] -->
```

3개 필드 필수 (모두 string, AI 가 매번 실데이터로 산출):
- `anchor` — 진입가 산출에 사용한 시세 앵커 조합 (앵커 활용 narrative 와 일치)
- `ts` — 분석에 사용된 데이터 시점 (오늘 brief 작성 시각)
- `src` — 시세 데이터 source (`yfinance` 또는 `yfinance:stale`)

> retro skill 이 이 메타로 *"어떤 데이터로 판단했나 → 왜 틀렸나"* 진단. 사용자에게는 안 보임 (HTML comment).

**carry-over 반복 노출 피로도 — 시각 weight 점진 축소** (SKILL.md § Step 6 "반복 노출 피로도 관리" 와 한 쌍):
- carry-over 가 같은 narrative 로 오래 반복될수록 카드의 시각 weight 를 *점진 축소* (방식 AI 자율 — border 톤 다운 / muted color / 카드 압축 layout / narrative 압축 등)
- 단, *오늘 새 근거* (가격 큰 변동·새 catalyst·thesis 강화) 가 있으면 다시 풀 강도로 표시 + 라벨에 `Day N — 오늘 강화` 표기
- 정해진 N회 임계값 X — AI 가 매일 직접 판단

## 0개 empty state 카드 (필수 — 카드 자체는 생략 X)

오늘 추천 0개일 때 — *카드를 빼지 말고* 명시적으로 0개 표시:

**필수 포함:**
- 헤더: "🆕 추천 매수 후보" (다른 카드와 같은 헤더 양식)
- 명시: "**오늘은 신규/추가 매수 권장 없음**"
- 사유: "fresh 발굴 + carry-over 통합 결과 *오늘 기준 진입 매력이 충분한 후보 없음*. 현금 보유가 최선."
- 보충 (muted): "추천 0개는 정상. 매일 액션이 있어야 한다는 압박은 과매매 위험. 내일 brief 에서 새 catalyst 보고 재검토."

**시각 요구사항:**
- **다른 카드와 *동등한 시각 weight*** — 작거나 비어 보이지 X
- **단순 layout** — 중첩 `<ul>` 같은 들여쓰기 구조 피함, 짧은 paragraph 1-2개로 충분
- 후보 카드 강조 요소 (border 등) 와 *살짝 차별* (예: muted color border) — *완전 분리는 아님*, 같은 섹션임을 시각으로 보여줌

## 헤지 제안 카드 (8c, 조건부 — 위기/이벤트 모드 한정)

**일반 매수 후보 카드와 *시각 명확 분리*** — 헤지는 *수익 추구 X, 단기 보험*. 사용자가 *즉시 다른 카테고리* 임을 인식 가능해야.

**시각 분리 요구사항:**
- 다른 색 border / 다른 background / 명확한 아이콘 (🛡️) 중 *최소 하나 이상*
- 색상 톤: 후보 카드의 accent 와 *다른 색* (예: 노란/주황 계열)
- *섹션 위치도 후보 list 뒤에 별도 그룹*

**필수 포함:**
- 🛡️ 단기 헤지 제안 (헤더)
- 목적 — 왜 지금, 무엇을 보호
- 수단 카테고리 (지수 인버스 / 섹터 인버스 / 변동성 / 단기채 등 — 구체 ticker 는 AI 그날 선택)
- 권고 사이즈 — 포트폴리오의 *일부만* (완전 상쇄 X)
- 예상 보유 기간 — *장기 보유 금지*
- 해제 조건
- 손절/무효화 조건
- *왜 매도보다 헤지가 나은가* (세금·재진입·thesis 유지)
- ⚠️ 경고: "인버스/레버리지 상품은 decay·추적오차 — 장기 보유 대상 X"

**렌더링 조건:**
- 위기 모드 (Step 3 위기 강함 판정)
- 평상 모드 + 강한 이벤트 리스크 (FOMC·CPI·주요 어닝 직전)
- 평상 모드 + 이벤트 없음 → **카드 자체 미렌더링**

**active hedge 추적 시:** 같은 카드 패턴 재활용, 상태를 "active 추적 중" 으로 표기 + 해제 권고 narrative 추가.

## 비중 카드 (4c)

**단계 사다리(🔴🟠🟡) 없음.** 비중 숫자는 데이터로 충분 — 카드는 *해석이 필요한 것만* 표시.

**필수 요소:**
- **단일 종목 고유위험**: 한 종목 비중이 고유 사고 시 영구손실이 클 수준이면 `ℹ️ [종목] 단일 X% — 고유위험 ↑ (매도 신호 아님, 추가매수 가드·주의)` 한 줄
- 해당 없으면: ✅ 안정 한 줄
- **국가·섹터 비중은 평시 표시 X** (분산 노출 + 자연 희석 — narrative 필요 시만)
- 위기 모드 시: 디리스크 우선순위(단일 종목·고베타부터)로 전환 — `crisis-playbook.md`
- **% 임계값 spec 박지 X** — AI 자율 판단, 매도 verdict 아님

## 보류 후보 카드 (8b, 조건부)

AI 가 매력적이라 판단했으나 timing·환율·이벤트·현금 같은 *맥락 요인* 으로 보류 권고한 후보 있을 때만.

**필수:**
- 🔍 헤더: "AI 가 보류 권고한 후보"
- 종목 + 보류 사유 (맥락 요인)
- 한 줄 평 — 어떤 매력 있는데 왜 미루는지

**판단 메타** — 카드 끝에 HTML comment:
```html
<!-- meta: why_not=[보류 사유 핵심 단어, 예: fx_volatility|event_pending|cash_low|market_extended], ts=[YYYY-MM-DDTHH:MM KST] -->
```

> ⚠️ **`concentration`(집중도) 은 평시 보류 사유로 쓰지 않는다** — SKILL.md § 비중 모니터링 "평시 동작" 참조. 집중 테마와 겹치는 후보는 *보류* 가 아니라 그 후보 카드에 "중복 경고" 1줄만 추가하고 정상 ranking 한다. 보류는 `timing·환율·이벤트·현금` 같은 비중 무관 맥락 요인일 때만.

> retro 가 *"보류 후보가 결과적으로 옳았나 (놓친 기회)"* 분석 input 으로 사용.

없으면 카드 자체 생략.

## 시세 앵커 가격 표시 (공통)

종목별 익절/손절/진입가 표시 시:

- **값 옆에 *AI 가 사용한 앵커 조합* 근거 명시** (사용자 검증 가능)
- 표시 형태: `진입가 $[값] (근거: [앵커 조합 narrative])` — 가격·앵커 조합 모두 매번 AI 직접 산출
- `anchors_source == "yfinance:stale"` 인 경우 `(stale: YYYY-MM-DD 캐시)` 명시
- 이틀 연속 stale 이면 본문에 `⚠️ 시세 앵커 stale 2일 연속 — yfinance 점검 필요` 한 줄

## 출력 검증 (semantic checklist)

대시보드 작성 후 자체 점검:

- [ ] **12개 표준 섹션** 순서대로 배치됐는가
- [ ] **모드 배너** 시각 강도가 모드와 매칭되는가 (위기 = 강한 경고 / 안정 = 차분 등)
- [ ] **위기 모드 시 trigger 한 줄** 배너에 명시됐는가
- [ ] **🎯 오늘 결론 카드 (섹션 2)** 가 모드 배너 바로 아래에 있고 3줄 요약 (액션 yes/no + 무엇·얼마 또는 왜 현금이 최선) 포함됐는가
- [ ] **카드 간 시각 weight 균등** — 작거나 비어 보이는 카드 없는가 (오늘 결론 카드는 *살짝 강조* 예외)
- [ ] **한 brief 내 시각 일관성** — 같은 종류 카드는 같은 스타일, 같은 색은 같은 의미
- [ ] **신규 후보 카드 필수 요소** 다 있는가 (추천 사유·강점·약점·hidden risk·진입/손절/익절·사이즈+근거)
- [ ] **점수표·매력 N/M 배지 없음**
- [ ] **0개 empty state 카드** 가 *생략 X* 명시적 표시 (카드 weight 다른 카드와 동등)
- [ ] **조건부 압축 4개 섹션** (보유 분석 6 / 세금 10 / 현금 11 / 일정 12) 가 *완전 생략 X* — 신호 없으면 한 줄 압축으로라도 노출됐는가
- [ ] **거시 지표/시세 앵커 정의 노출** — 거시 환경 카드의 각 지표 옆 본질 정의 (괄호) + 진입가 narrative 의 앵커 이름 옆 정의 노출됐는가 (초보자 친화)
- [ ] **헤지 카드** (있는 경우) 일반 후보와 시각 명확 분리됐는가
- [ ] **4c 비중 카드** 가 단일 종목 고유위험 정보(ℹ️)만 표시하고 *매도 verdict 로 읽히지 않는가* (단계 사다리 제거 확인)
- [ ] **4b 상대성과** + **4c 비중** 카드가 포트폴리오 안에 있는가
- [ ] **시세 앵커 가격** 에 *앵커 조합 근거* 명시됐는가
- [ ] `anchors_source` stale 인 경우 표기됐는가
- [ ] **오래된 carry-over 후보 카드** 시각 weight 가 *점진 축소* 됐는가 (반복 노출 피로도 관리)
- [ ] **매수 전 확인사항** narrative 가 오늘 추천에 맞춰 작성됐는가
- [ ] **텔레그램 한 줄 요약 detail** 들이 *모두 대시보드에* 들어있는가 (button 누르면 충분한 정보)

> **회고는 별도 `retro` skill 의 대시보드에** — daily-briefing 대시보드엔 회고 카드 없음.
